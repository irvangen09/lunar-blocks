# Security Policy

## Supported Versions

Only the most recently released version of Lunar Blocks receives security fixes. Please make sure you're on the latest version before reporting an issue.

## Reporting a Vulnerability

If you find a security vulnerability in Lunar Blocks, please **do not** open a public GitHub issue.

Instead, report it privately through GitHub's [security advisory form](https://github.com/irvangen09/lunar-blocks/security/advisories/new) for this repository. This lets us confirm and fix the issue before it's publicly visible.

Please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce it (a minimal WordPress setup, if relevant).
- Any proof-of-concept code, if you have one.

Since this plugin is currently maintained by a single person, response times aren't guaranteed, but reports are taken seriously and addressed as quickly as possible. You'll get a reply acknowledging the report, and credit in the fix's changelog entry unless you'd prefer otherwise.

## Scope

This policy covers the Lunar Blocks plugin code in this repository. It does not cover vulnerabilities in WordPress core, in themes, or in other plugins — please report those to their respective maintainers.
